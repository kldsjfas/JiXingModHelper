吉星派对 Mod 助手 v1.4.1

一、第一次使用
1. 将整个 ZIP 解压到你有写入权限的新文件夹，保留 _internal 和 tools。
2. 双击 JiXingModHelper.exe，确认窗口顶部显示 v1.4.1。
3. 首页会自动连接游戏；未找到或连接了另一服时，使用「选择游戏位置」指定安装目录或实际游戏 EXE。
4. 到「浏览资源」刷新索引，按中文分类看缩略图，也可搜索中文用途、编号或原始名称。

二、怎么发给别人
直接转发原始的完整 ZIP。对方完整解压后运行，不要只发送单个 EXE。
官方版本：https://github.com/kldsjfas/JiXingModHelper/releases/latest

三、从旧版升级
关闭所有旧助手，解压到新文件夹，不覆盖旧版。
保留旧版目录、modkit_data、made_mods 和备份。
旧版已安装 Mod 时，先退出游戏，用旧版禁用或还原，再由新版安装。
重复打开同一版本会切回已有窗口；确认窗口顶部版本，避免误开旧快捷方式。

四、遇到资源识别或导入问题
首页点击「检查资源」，再点「导出诊断报告」，把 TXT 和操作时的完整错误一起反馈。
报告在本地生成，不会自动上传。报告包含本机路径，发送前可自行检查。
不要反复清理游戏缓存，也不要手动覆盖 catalog 或删除备份。

五、系统与组件
适用于 Windows 10/11 x64，运行助手所需的 Python 和 .NET 已随包提供。
编译功能插件另外需要 .NET SDK，并在「功能插件」下载官方 CesiumLoader SDK。
界面需要 Microsoft Edge WebView2 Runtime。若系统缺少，请从微软官方页面安装 Evergreen Windows x64 Runtime：
https://developer.microsoft.com/microsoft-edge/webview2/
材质表情的 GIF/APNG/WebP 输入和预览不需要 FFmpeg。
普通视频转换和旧 CRI 预览可运行「获取表情转换组件.cmd」下载并校验 FFmpeg。
音频试听可运行「获取音频解码组件.cmd」下载并校验对应组件。

六、保存与安装
保存只改作品集；安装、启停、卸载和还原前必须退出游戏。
不同 Mod 修改同一资源包时，不能自动合并。动态作品请先检查成品预览，再在游戏中逐项确认效果。

七、临时暂停与工坊连接
临时恢复本助手修改前的资源，可在 Mod 管理暂停全部 Mod，记录和安装副本保留，之后能逐个启用。完全还原会清空安装记录与安装副本，原文件备份保留。
工坊连接失败时可重试；已有完整 ZIP 可前往 Mod 管理导入。软件不会修改系统代理或关闭证书验证。

八、功能插件
在「功能插件」创建帧率或加载通知工程，可编辑源码并编译为独立 ZIP。
工程与成品保存在 made_mods/plugins，配合 CesiumLoader 加载，游戏内效果待实测。
这是 1.4.1 正式版，完整操作与支持范围见「使用说明.md」。

九、角色动画
进入「角色动画」为同一角色分别导入待机、行走、战斗等素材，支持静态图片、动图、PNG帧目录和视频。
预览读取已保存的真实帧，导出的ZIP在Toys角色素材库导入并加入方案，需要CesiumLoader与CharacterSkinMod。

十、视频动态卡面清晰度
1.4.1按源视频规划有效画面像素。旧的低清动态作品需要重新导入原视频并保存，再导出或安装作品集。
缺失动作可能播放待机或上一张自定义帧，角色编号需与游戏内部ID一致，游戏内效果待实测。

十、逐帧导出再修改
在「动作片段」选择动画，点击「导出PNG帧包」，解压后修改PNG并保留时序清单。
点击「用帧素材替换此动作」衔接角色动画工作台，导入解压目录即可沿用原时长制作动作包。
